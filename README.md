# 🍅 Pomodoro Timer

A clean, desktop Pomodoro Timer built with **Python** and **Tkinter** to help you stay focused and productive using the [Pomodoro Technique](https://en.wikipedia.org/wiki/Pomodoro_Technique).

![Python](https://img.shields.io/badge/Python-3.x-blue?logo=python&logoColor=white)
![Tkinter](https://img.shields.io/badge/GUI-Tkinter-orange)
![License](https://img.shields.io/badge/License-MIT-green)

---

## ✨ Features

- ⏱️ **25-minute Pomodoro** work sessions
- ☕ **5-minute Short Breaks** between sessions
- 🛌 **15-minute Long Breaks** after every 4 Pomodoros
- 🔄 **Auto-switching** between work and break tabs
- 📊 **Pomodoro Counter** to track completed sessions
- ⏭️ **Skip** the current timer
- 🔁 **Reset** everything and start fresh
- 🧵 **Threaded timer** — UI stays responsive while counting down

---

## 📸 Preview

The app features a tabbed interface with three modes:

| Tab | Duration | Purpose |
|-----|----------|---------|
| Pomodoro Timer | 25 min | Focused work session |
| Short Break | 5 min | Quick rest between sessions |

## 🚀 Getting Started

### Prerequisites

- **Python 3.x** installed ([Download Python](https://www.python.org/downloads/))
- `tkinter` (comes pre-installed with Python on most systems)

### Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/sahil75416/Pomodoro_Timer.git
   cd Pomodoro_Timer
   ```

2. **Run the app**
   ```bash
   python main.py
   ```

That's it — no extra dependencies needed! 🎉

---

## 🎯 How the Pomodoro Technique Works

1. 🍅 **Work** for 25 minutes (one "Pomodoro")
2. ☕ Take a **5-minute short break**
3. 🔁 Repeat steps 1–2
4. 🛌 After **4 Pomodoros**, take a **15-minute long break**
5. 🔄 Start over!
